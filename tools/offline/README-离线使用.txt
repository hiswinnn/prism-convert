棱镜 Prism · 离线使用说明
══════════════════════════════════════════════════════════

这是什么
--------
「棱镜」是一个 100% 在本地运行的纯前端文件转换器。它不联网也能用：
所有转换都在你的设备上完成，没有任何服务器接收你的文件。

它只借用了浏览器来显示界面和跑计算（纯前端程序没有别的运行方式），
就像打开一个本地网页，但这个网页不依赖网络、也不会上传任何东西。

怎么用（电脑端，双击即可）
--------
1. 双击「启动棱镜.bat」
2. 浏览器会自动打开 http://127.0.0.1:4780/ ，直接开始用
3. 用完直接关掉浏览器窗口，再关闭那个黑色命令行窗口即可

断网也能用吗？
--------
能。这个文件夹里已经打包了全部依赖，包括音视频引擎（约 30MB 的
ffmpeg），所以断网状态下：

  · 聊天记录、文档、表格、图片、PDF、压缩包、字幕 —— 全部可用
  · 音视频转码 —— 首次会从本文件夹加载引擎，之后完全离线

「启动棱镜.bat」做的只是在本机起一个"文件服务"（不联网、不对外），
让浏览器能读取本文件夹里的文件。它不是云端服务，关掉窗口就停。

需要什么环境？
--------
只需要 Node.js（免费，https://nodejs.org 下载 LTS 版即可）。
你当前这台电脑已经装了，所以直接双击就能用。

手机端怎么用？
--------
手机没有「双击运行」这种方式。手机上最省事的做法是：

1. 手机浏览器打开 https://hiswinnn.github.io/prism-convert/
2. 点浏览器菜单「添加到主屏幕 / 安装」，它会像 App 一样装在桌面
3. 之后离线也能打开使用（应用外壳已缓存；音视频引擎首次使用时下载一次）

如果你一定要手机完全离线也能用，可以把本文件夹整个拷进手机（U 盘/数据线），
但手机浏览器一般不允许直接打开本地的多文件网页，所以推荐用上面的「添加到主屏幕」方式。

隐私
----
本程序不联网、不传文件、不埋点。断网后用，更放心。
